# Human Layer MVP

The first version is for **one user**.

Do not begin with a marketplace, social network, giant ingestion platform, or enterprise product.

The first question is:

> **Can one person build a Sphere, talk to it, correct it, and feel that it is meaningfully theirs?**

## v0 experience

### 1. Import
The user imports:
- AI chat exports
- notes / text files
- documents
- browser history export
- calendar export
- optional public URLs / usernames

### 2. Parse
Each source becomes evidence with provenance.

### 3. Build the Sphere
The system extracts:
- facts
- self-assertions
- goals
- values
- constraints
- recurring patterns
- important relationships
- decisions
- predictions
- outcomes
- unresolved contradictions

### 4. Dialogue
The user opens chat and can ask:

- "What do you think is true about me?"
- "Why?"
- "Show me the evidence."
- "Where are you least certain?"
- "What do my actions contradict?"
- "What changed this year?"
- "What keeps repeating?"
- "What do I claim to value versus what receives my time?"
- "What would a stranger infer from my public footprint?"

### 5. Correct
Every important answer exposes the claims beneath it.

The user can mark:
- correct
- wrong
- outdated
- missing context
- private
- never use this

### 6. Observe the model changing
The Sphere should visibly show:
- claims strengthened
- claims weakened
- corrections
- contradictions
- newly discovered uncertainties

This is the core psychological moment.

### 7. Export
The entire Sphere can be exported as JSON.

Later, scoped exports can be created for:
- tutor
- travel agent
- business agent
- health assistant
- finance assistant
- simulation engine

## First magic test

After importing a meaningful amount of data, ask:

> **"Tell me something important about myself that is supported by evidence, that I did not explicitly tell you in one sentence."**

Then inspect the evidence.

Then argue with it.

If the correction loop feels powerful, the primitive is alive.

## Explicit non-goals for v0

- "knowing what everyone secretly thinks"
- scraping private conversations the user cannot lawfully access
- claiming the Sphere is objective truth
- autonomous action
- medical / legal / financial decision automation
- replacing the user's judgment

## Success condition

The user says:

> **"I would be genuinely upset if I lost this model of myself."**

That is the retention test.
