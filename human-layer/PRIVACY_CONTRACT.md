# Human Layer — Ownership Contract

This is a product principle, not legal language.

If the Sphere is a computational extension of a human life, ownership cannot be cosmetic.

## The contract

### 1. The Sphere belongs to the human
The service may process it. The human owns the continuity.

### 2. The user can inspect the model
Important claims should be visible and explainable.

### 3. The user can challenge the model
Corrections are preserved as first-class data.

### 4. The user can export the Sphere
The core representation should not be trapped in one provider.

### 5. Access is scoped
A service should receive only the part of the Sphere needed for the task.

### 6. No secret sale of the Sphere
A product that monetizes the user's deepest personal model against the user violates the reason the system exists.

### 7. No hidden authority expansion
Knowing more about the human does not grant more permission to act.

### 8. The user may leave
Exit must be technically possible.

## The principle

> **A model of a human should serve the human it represents.**
