# Contributing

Agency Layer is a public research lab.

The most useful contribution is not agreement. It is **specific pressure on the model**.

## Good contributions

- Show that a primitive already exists in prior work.
- Identify a technical impossibility or hidden assumption.
- Provide a real-world agent failure case.
- Propose an adversarial scenario.
- Demonstrate that a rule creates unnecessary friction.
- Find a case where the framework still permits illegitimate authority.
- Suggest a more precise abstraction.
- Reproduce or falsify an experiment.

## When opening an issue

Please include:

1. **Claim** — what you think is wrong, missing, redundant, or important.
2. **Why it matters** — what breaks if we ignore it.
3. **Evidence** — papers, code, incidents, protocols, examples, or reasoning.
4. **Suggested consequence** — what should change in the spec, experiment, or implementation.

## Research norm

If you prove us wrong, that is progress.

We will maintain a changelog explaining which criticisms changed the project.

## Scope

We are especially interested in:

- agent authorization
- delegated authority
- capability security
- identity
- memory
- provenance
- human-computer interaction
- multi-agent systems
- distributed systems
- reversibility
- accountability
- governance
- agent evaluation
